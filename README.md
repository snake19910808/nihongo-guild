## ✨ 核心特色與六大冒險系統

### 1. ☕ 溫柔公會看板娘兼專屬導師「詩織（Shiori）」
- **角色設定**：黑色優雅長髮、氣質溫柔成熟的大姊姊，冒險者公會的專屬接待員。
- **雙模智能對話**：
  - **線上 AI 家教**：支援 Google Gemini 2.5 Flash / Pro API，以白話、親切口吻耐心解答文法疑問與文化背景。
  - **每日三句造句批改**：每日第 5 項委託「日語造句練習」，由詩織親自審閱並給予即時回饋、文法糾錯與讚美。
  - **離線智慧降級（Fallback）**：無網路或未輸入 API Key 時，內建 50+ 條精選日系情境互動台詞，保證學習不中斷。
- **生動立繪反應**：擁有正常微笑 (`shiori_normal`)、害羞臉紅 (`shiori_shy`)、燦爛開心 (`shiori_happy`) 三種表情立繪，隨互動與好感度切換。

### 2. 🟢 三段式假名注音引擎 (Furigana Ruby System)
- **三種切換模式**：
  - 🟢 **全部顯示 (All)**：所有漢字皆強制附帶假名注音（Ruby `<rt>` 標籤），零基礎新手友善！
  - 🟡 **智慧模式 (Smart)**：已掌握或連續答對多次的熟練漢字自動隱藏注音，未掌握者保留注音。
  - 🔴 **全面隱藏 (Off)**：完全隱藏注音，模擬 JLPT 檢定真實考場閱讀環境。
- **點擊即查詳細字典 (Click-to-Inspect)**：點擊任何單字或漢字晶片，即刻彈出字典卡片，顯示音讀、訓讀、例詞、例句與詞性。
- **真人語音朗讀 (TTS)**：串接 Web Speech API，一鍵聆聽道地標準東京腔發音。

### 3. 📜 57 週 398 天全能課表（聽・說・讀・寫均衡發展）
- **備考目標**：2027 年 12 月 5 日 JLPT N3 檢定合格（2027 年 7 月 N4 自由選考練兵）。
- **實體教材精確對應**：
  - 出口仁老師《大家學標準日本語 初級本》第 1～12 課（P018～P182 + 42 個關鍵文法學習目標 + 本地教學影片無縫對應）。
  - 《大家的日本語 初級 I》第 1～12 課（P14～P159 聽力、句型練習 A/B/C、代換練習）。
- **每日六大闖關任務（每天約 1.5～2 小時）**：
  1. 📖 **文法與課文精讀**（25分鐘）
  2. 🎧 **聽力跟讀與回音法（Shadowing）**（20分鐘）
  3. 🗣️ **口說大聲朗讀與錄音自我檢視**（15分鐘）
  4. ✍️ **單字與漢字抄寫默背**（20分鐘）
  5. 📝 **詩織每日三句日語造句與批改**（20分鐘）
  6. ⚔️ **RPG 討伐或記憶神殿複習**（20分鐘）

### 4. ⚔️ 《歧路旅人（Octopath Traveler）》HD-2D 弱點破盾戰鬥系統
- **橫向對峙舞台與行動軸 (Timeline)**：
  - 頂部行動順序軸即時顯示敵我雙方出手順序與暈眩標記。
  - 左側魔物生態陣營 ⟷ 中間 Canvas 打擊弧光與噴發火花 ⟷ 右側我方像素紙娃娃精靈。
- **弱點與破防機制 (Weakness & Break)**：
  - 每隻魔物擁有 2～6 層護盾（`🛡️ 3`）與多種屬性弱點（如：🔤 羅馬拼音、🈂️ 片假名、📖 單字詞義、🏮 漢字音讀、📜 核心文法、🎧 聽力理解、🗣️ 發音朗讀）。
  - 未知弱點以 `[ ? ]` 剪影覆蓋，擊中弱點瞬間破除 1 層護盾並點亮弱點標記。
  - 當護盾降為 0，引發全螢幕震撼金色「⚡ BREAK！」光芒與音效，魔物進入暈眩癱瘓狀態，全隊出招享受 200% CRITICAL 暴擊傷害！
- **純 Web Audio 打擊音效合成器**：
  - 零外部音效相依，由瀏覽器底層音訊合成器即時運算輸出揮劍斬擊聲、金屬碎盾聲、BREAK 碎玻璃清脆爆裂音與勝利小號琶音（Fanfare）！
- **52 款豐富魔物生態庫 (`data/monsters.json`)**：
  - 五十音平原、N5 迷霧幽林、N4 遠古遺跡、N3 魔王神殿四大生態。
  - 收錄 40 款特色小怪 + 8 款菁英小 Boss + 4 款世界守門大魔王，每 5 戰遭遇菁英、每 10 戰迎擊守門魔王！

### 5. 🛡️ 開局創角與冒險者紙娃娃換裝系統 (Avatar Customizer)
- **自由自訂專屬勇者**：
  - 玩家姓名（最多 12 字，預設「旅人アルス」）。
  - 性別外觀（♂ 青年冒險者 / ♀ 少女冒險者）。
  - 4 款髮型（俐落短髮、浪人長髮馬尾、熱血刺蝟頭、飄逸長髮/雙馬尾）。
  - 7 款髮色 Swatches（曜黑、深褐、流金、緋紅、冰藍、銀灰、紫羅蘭）。
  - 3 款眼睛樣式（堅毅明眸、溫柔圓眼、銳利專注）與 5 款眸色。
  - 4 種膚色與《歧路旅人》四大經典職系（劍士・藍銀輕鎧、學者・翠綠法袍、商人・褐黃旅行裝、舞者・緋紅華服）。
- **即時像素畫布精靈 (Pixel Canvas Sprite)**：
  - 動態支援呼吸待機 (Idle)、前衝揮劍斬擊 (Attack)、受擊白閃 (Hit)、勝利高舉武器 (Victory) 四大動作姿態！

### 6. 🎓「聽・說・讀・寫」四維度深度互動全面落地
- **🗣️「說」：語音音素比對與發音語感評分儀 (`SpeechEvaluator`)**：
  - 點擊麥克風朗讀目標日語句子或假名，系統進行音素比對與編輯距離分析，打出 0～100 發音分數與 S/A/B/C 評級。
  - 精準抓出初學者盲點（如「つ」念成「す」、「ふ」咬下唇等），詩織親自給予嘴型與發音指導！
- **🖌️「寫」：五十音與漢字九宮格筆順手寫板 (`HandwritingBoard`)**：
  - 支援觸控筆、手指與滑鼠繪製，具備淡紅色九宮格米字輔助線、淡色筆順陰影與宣紙黑墨筆跡。
  - 具備清空、撤銷、筆墨覆蓋度與中心重心平衡評分！
- **🎧「聽」：情境長句聽解與聽寫挖空 (`ListeningReadingModule`)**：
  - 支援 0.8x 慢速與 1.0x 標準日語語速無縫切換，專注聆聽連音與長句。
  - 聽寫填空（Dictation）：聽取道地會話，將缺漏的助詞或假名填入。
- **📜「讀」：公會村民委託信短文閱讀測驗**：
  - 每日增加村民日文求助信（麵包師傅、酒館老闆娘、圖書館管理員、見習魔導士等），附帶三段式假名注音與閱讀理解題目！

### 7. 🎴 記憶神殿日常化（每日 5～15 張無痛通關）
- **告別 3,700 張卡片負擔**：預設模式直接綁定 398 天進度，每天只安排當天需記憶與到期複習的 5～15 張核心卡片。
- **神殿修煉完成回饋**：當天背完立即觸發「🎉 今日抽認卡修煉大成功！」，自動勾選公會今日打卡委託。
- **全庫自主檢索模式**：想加碼衝刺的冒險者可一鍵切換至全庫自由篩選模式。

### 8. 👾 冒險圖鑑「寶可夢式點亮收集」與成就百分比
- **未遭遇魔物剪影覆蓋**：未擊敗之魔物顯示神秘灰色剪影 `???` 與未知弱點。
- **擊敗點亮收服**：在討伐戰鬥中擊倒魔物後，圖鑑瞬間發光點亮、蓋上「✨ 已收服」綠色印章並揭露數值與全部弱點。
- **全書收集率統計**：頂部儀表板即時計算「🏆 冒險總收集率、👾 魔物圖鑑、🀄 常用漢字、📘 核心單字」百分比！

### 9. ☁️ 跨裝置雙端進度同步（PC 💻 ⟷ 手機 📱）
- **雙層儲存架構**：
  - **本地層 (Local Storage)**：離線狀態下全功能順暢運行，隨時紀錄每筆經驗值與任務進度。
  - **雲端層 (GitHub REST API)**：透過私人儲存庫 (`nihongo-save`) 進行一鍵備份與還原，支援衝突檢測與多裝置進度接軌。
- **免帳號負擔**：使用個人的 GitHub Personal Access Token (Fine-grained)，完全不需要架設額外後端伺服器！

## 🚀 快速上手指南

### 方式一：線上即開即用 (GitHub Pages)
直接使用瀏覽器開啟已部署的 GitHub Pages 官方站點：  
🔗 **[https://snake19910808.github.io/nihongo-guild/](https://snake19910808.github.io/nihongo-guild/)**

> 💡 **Pixel 8 Pro 手機安裝為 App**：  
> 1. 用 Chrome 開啟上述網址。  
> 2. 點選右上角三個點選單「⋮」 ➜ 選擇「**加到主畫面**」（或「**安裝應用程式**」）。  
> 3. 手機桌面上即會出現「**日語公會**」的專屬 App 圖示，支援全螢幕與離線離線快取使用！

### 方式二：本機啟動（離線或區域網路連線）
1. 電腦已安裝 Node.js (v18 以上)。
2. 在專案根目錄開啟終端機執行：
   ```bash
   node server.js
   ```
3. 瀏覽器開啟：`http://localhost:8000`
